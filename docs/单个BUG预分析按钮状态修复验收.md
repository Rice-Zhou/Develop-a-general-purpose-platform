# 单个 BUG 预分析按钮状态修复验收（0.9.1）

日期：2026-10-21。

## 修复范围

根因：后端已有按代码项目、来源绑定和问题 ID 的活动任务去重，问题卡片没有使用该身份关联活动任务；全局请求 loading 也会短暂禁用其他问题。

按钮现在按对应问题的任务显示“提交中”“排队中”“分析中”“取消中”，期间禁用该问题的两种分析入口。提交期间用同步请求锁拦截重复点击，任务创建后由现有任务列表驱动状态。其他问题可继续提交，任务结束或取消后恢复入口。没有新增队列或修改后台去重规则。

## 验证

- 修改后的回归在旧版 0.9.0 上失败：运行中的 A-1 没有“分析中”按钮。
- 新版 3 项打包桌面回归通过：账号和项目匹配、独立日志与分析队列、日志下载和当前代码分析。
- 队列测试覆盖提交中禁用、其他问题仍可点击、运行中与排队中禁用、取消后恢复。
- TypeScript 类型检查、受影响文件 ESLint、git diff --check 通过。
- 打包成功，ZIP 中 83 个文件与便携目录逐一 SHA-256 校验一致。
