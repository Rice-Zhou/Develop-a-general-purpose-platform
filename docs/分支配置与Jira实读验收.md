# 0.3.1 分支配置与 Jira 实读验收

## 变更范围

按用户补充，将分支配置分成两个动作：先只读检测所选目录的当前分支，再由用户确认采用或自由填写目标分支。目标分支仍保存在原有 RepositoryBinding.branch，未新增第二份分支配置或改变数据库 schema。

- 选择、输入目录后延迟 400 毫秒读取；“重新读取”可刷新外部 Git 操作后的状态。
- 点击“使用当前分支”才填入目标分支，自动读取及重新读取不会覆盖手动配置。
- 路径变化、组件卸载后忽略旧请求结果，避免串目录。
- detached HEAD、无效目录和非工作树根目录明确展示，保留用户已填写的分支。
- 固定 IPC 方法 readCurrentBranch 只接受目录，不接受命令或 Git 参数。与原有 inspect 共享根目录和当前分支读取逻辑。
- 只运行本地 Git 读取命令，不 fetch、checkout、stash、reset 或清理文件。保存仍只保存配置；分析时沿用原有分支、upstream、工作树和快进检查。
