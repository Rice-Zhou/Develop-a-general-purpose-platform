## 独立评审与修复

已完成一次独立全量代码评审，没有待处理的 Critical、Important 或 Minor。评审发现的五项问题均先复现失败，再修复并通过回归与全量测试：

1. 快进覆盖 ignored 本地文件：使用 `--no-overwrite-ignore`，验证原文件与 HEAD 均保留。
2. status 在检查前执行 clean/process 过滤器：先通过 ls-files/check-attr 被动检查有效属性，验证外部过滤器的副作用标记没有产生。
3. 服务崩溃遗留 Git 子进程：初始化前加入 Windows Job Object，确认旧作业活动进程归零后才允许服务恢复；真实服务及子进程测试通过。
4. 停止失败但等待 close 导致错误不返回：立即报告 PROCESS_STOP_UNCONFIRMED 并阻断队列；验证真实子进程仍存活时错误已经返回，随后由测试回收。
5. linked worktree 的 Git 操作路径是绝对路径：按绝对/相对路径分别处理，真实 worktree 的未完成操作被正确阻断。

桌面验证另发现并修复了 renderer 输出目录、Vite 外置原生依赖未打包和装饰图标影响无障碍名称的问题。每次失败均保留可见诊断，没有改用模拟后端。

## 实施裁定及代价

以下按实际作出顺序记录：

1. 使用随工具提供的 Node 24.19.0，不修改全局 Node；从源码开发的机器仍需兼容 LTS。
2. Windows 上使用 PowerShell 记录技能工作流，替代 POSIX 辅助脚本；过程账本需要人工核对。
3. 锁定 TypeScript 5.9.3 与兼容工具链，刷新不一致的 npm 元数据；升级依赖需要重新验证兼容性，没有使用 force 或 legacy-peer-deps。
4. 首阶段全局串行执行准备任务；不同项目也会排队，吞吐量受限。
5. 使用 `refs/local-dev-platform/snapshots/<sha>` 保留历史提交；分析仓库会保留相关历史对象，未来需明确保留期限。
6. 使用 Koffi 与 Windows Job Object 保证崩溃后子进程所有权；当前发布范围限定 Windows x64，系统策略拒绝管理时停止恢复。
7. 对锁定的 better-sqlite3 13 与 Koffi 3 使用自带 Node-API 二进制并显式保留生产依赖，不重复编译；升级必须重跑打包后测试。
8. 将测试助手的短轮询预算改为明确的 30 秒截止时间，保持后端单测 60 秒上限；繁忙机器最多较晚暴露任务不结束，错误包含实际任务状态，不增加自动重试。

无延期 Minor。

## 使用与边界

- 使用 ZIP 时先完整解压，再运行其中的 LocalDevPlatform.exe，不要只移动单个 exe。
- 系统需要可执行的 Git；Windows 应用运行不需要另装 Node/Python。配置目录应是开发者自行下载的独立分析工作树。
- 不自动 clone、切分支、stash、reset、清文件、创建合并提交或推送；Git LFS、过滤器和子模块目前明确拒绝。
- 备份包含项目、任务和快照元信息，不包含代码仓库、需求原文和可移植凭据。删除或移动分析仓库会影响历史代码读取。
- 数据库目前只有初始 schema v1，没有已有 v1 到未来 v2 的迁移。未来引入升级迁移时必须补迁移前备份与回滚验证。
- 安装程序尚未签名。已验证打包目录中的真实程序；没有在当前电脑执行安装、卸载或 SmartScreen 签名信任测试。
- 当前环境下载 Electron 需要本机已配置代理与 Node 的 `--use-env-proxy`；源码未写入代理地址、凭据或禁用 TLS 的配置。
- 自动审批拒绝了旧生成目录 `apps/desktop/.vite` 的递归清理，原因是策略拦截；该目录已保留。正确构建输出使用根 `.vite`，旧目录不参与打包或 lint。

## 主要命令

使用 Node 24、npm 11，正常环境可执行 README 中的 npm scripts。本次使用已存在的 Node 24 运行时直接调用相同工具：

```powershell
node node_modules/vitest/vitest.mjs run
node node_modules/typescript/bin/tsc --noEmit
node node_modules/eslint/bin/eslint.js .
node --use-env-proxy node_modules/@electron-forge/cli/dist/electron-forge.js package
$env:PLATFORM_EXECUTABLE = (Resolve-Path 'out/本地研发辅助平台-win32-x64/LocalDevPlatform.exe').Path
node node_modules/@playwright/test/cli.js test
```

最终发行文件从刚通过测试的应用目录生成，避免重打包后测试对象与发行对象不一致。首次 `make` 完整执行通过；末次使用 `make --skip-package`，Forge 提示该选项已弃用，后续应使用 `--from-package`。
