# 0.3.5 Jira 项目搜索交互

将原有“搜索输入 + 独立下拉选择”合并成一个搜索选择控件。输入项目名称或 Key 时，输入框下方直接显示匹配结果；点击结果后，在同一输入框显示项目名称（Key），收起列表。聚焦或点击输入框可再次展开，支持方向键高亮、回车确认和 Esc 收起。无匹配结果时明确提示，回车不提交表单；输入法组合输入期间不触发选择。

选中的项目仍以项目绑定为唯一数据来源，搜索文本仅是未确认的输入。修改文本立即清除旧绑定，必须重新选中真实项目后才能保存，避免后台收到与显示内容不同的旧项目。加载或读取失败时禁用控件；切换登录连接会重置搜索状态。登录、项目发现、身份校验、类型选择及单 Jira 绑定限制沿用 0.3.4。

改动集中在 `JiraProjectPicker.tsx`、`JiraProjectField.tsx` 和对应样式。鼠标选择保持输入框焦点，列表关联 combobox/listbox/option 语义；当前键盘高亮项通过 aria-activedescendant 关联，并滚动到可见区域。

验证：新交互用例先在 0.3.4 确认失败（仍存在独立搜索框），随后对新包验证名称/Key 搜索、鼠标选择、键盘确认、空匹配、Esc、编辑回显、修改文本清除旧绑定、账号/CLI 两种接入及旧多范围重选。项目选择及配置引导共 4 个桌面用例全部通过（25.5 秒）；增加展开列表截图后，账号完整流程再次通过（5.6 秒）。截图确认输入下方直接展示匹配项。TypeScript、ESLint 及安装包构建通过。
