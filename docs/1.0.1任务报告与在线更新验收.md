## 在线更新真实验证边界

本地网络直连 `https://api.github.com/repos/Rice-Zhou/Develop-a-general-purpose-platform/releases/latest` 返回 HTTP 404；继续直连仓库 API 同样返回 HTTP 404（当次 API 剩余配额分别 12/11）。因此不能验证真实公开 Release 下载，客户端准确提示更新仓库不可访问，不将其当作最新或无 Release。未使用 Token/AI 代理，没有上传或发布 Release。

本机 loopback 隔离服务验证真实桌面 IPC、一次提示、暂不更新后 reload 不再提示、手动检查、未点击前不取安装包、下载校验、403 与保留已校验包。仅 `PLATFORM_E2E=1` 允许本机测试源，真实安装在 E2E 中禁用；生产来源不能由渲染器改写。

尚未执行“旧安装版→新安装版”的真实覆盖安装或便携→安装版的实际转换。当前默认 userData 由相同应用名称决定，两种模式保持一致；若通过高级环境变量 `PLATFORM_DATA_DIR` 自定义目录，后续启动也需保留该变量。0.9.3 首次需手动启动/安装 1.0.1。启动安装器不等于升级完成，下次启动达到目标版本才报告成功。
