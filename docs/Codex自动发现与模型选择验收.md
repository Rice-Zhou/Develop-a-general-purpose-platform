# Codex 自动发现与模型选择验收（0.8.1）

日期：2026-10-21。开发目录：`D:/development/Develop-a-general-purpose-platform`。

## 交付行为

选择 ChatGPT / Codex CLI 执行方式后，平台搜索 PATH、npm Windows 原生包、Codex 桌面端安装目录和已有连接路径。对真实 exe 读取版本并去重，按语义版本选择最新版本，展示路径、版本和候选记录。发现实际文件却无法确认版本时停止并显示路径及原因，避免无法证明最新时退回旧版本。

通过所选 CLI 的 app-server 读取当前 ChatGPT 登录身份类型、订阅类型和分页模型目录；下拉列表只提供非隐藏的实际模型，不根据订阅名称猜测。元数据连接仅允许 initialize、account/read、config/read 和 model/list，不创建线程或模型任务，不返回账号邮箱、凭据或响应正文。进程有超时、输出上限和退出清理。

检测模型目录会检查执行配置一致性：模型执行继续使用隔离参数，拒绝自定义模型目录、非标准模型服务及 OpenAI provider 覆盖，防止配置中的假模型出现在下拉列表。新版 CLI 返回的标准 ChatGPT 服务默认地址可以正常读取。

编辑连接保留原 ID、默认连接及项目引用。保存前重新检测，CLI 路径变化、模型不可用或未登录时拒绝保存。原模型不在目录时要求重新选择，代理修改后要求重新检测；过期异步响应不能覆盖新配置。Claude Code 和模型 API 使用方式不变。

## 使用方法

1. 打开设置，创建或编辑 ChatGPT 订阅连接。
2. 等待自动检测；需要代理时填写 AI 专用代理，再点击“重新检测 Codex CLI 与模型”。
3. 确认所选最新 CLI 和模型；已有连接的模型仍可用时保留原选择。
4. 保存连接。已有连接继续供原项目使用，无需重新关联。

需先在 Codex CLI 或桌面端完成 ChatGPT 登录。平台不接管登录，不复制认证文件，也不修改用户 Codex 配置。模型目录成功只证明当前 CLI 返回可选模型，真实模型调用还可能受额度、服务状态和账号权限影响。
