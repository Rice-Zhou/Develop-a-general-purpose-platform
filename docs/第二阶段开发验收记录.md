## 待联调和已知限制

- 未向真实模型服务发送材料，未读取真实飞书文档，未使用现有 ChatGPT/Codex 或 Claude Code 账户执行分析。连接配置及协议代码不等于账户与服务已经验收。CLI 参数、登录方式、订阅额度、实际只读约束和供应商协议需按选定版本联调；不会把缺少配置的连接标记为完成。
- 仅通过本机 `lark-cli` 1.0.48 的帮助和 dry-run 验证 v2 参数。Codex 0.149.1 的帮助/功能参数已检查，Claude Code 未安装；未检查真实登录状态。订阅执行使用官方本机 CLI 的现有登录体系，应用不导入网页 Cookie 或托管订阅密码。
- PDF 不做 OCR；复杂版式、图片、扫描页以及 Word 页眉/页脚等附属部分会提示无法解析。报告属于静态分析，未自动运行项目测试，不应把静态“已实现”解释为运行验证通过。
- 初始代码索引有预算；模型采用有上限的完整响应和持久任务事件，没有逐 token 展示。
- 已知 Minor（延期）：Markdown 导出目前以需求 UUID 为标题，未完整包含原始需求文字、`sourceGaps` 和 `parseWarnings`。完整信息仍在应用报告内查看；导出文档不能当作无缺口的完整原文报告。
- 已知 Minor（延期）：解析 worker 失败有明确失败状态，但部分具体诊断码和中文原因目前被统一的子进程退出错误替代，修复损坏文档时可能需要额外检查。
- 生产依赖审计存在 3 项 moderate 传递项：Mammoth → argparse → sprintf-js。目前没有兼容的上游修复，npm 的 force 建议会降级到不兼容的历史 Mammoth。应用调用隔离 worker 中的转换 API，不调用相关 CLI 格式化入口；保留风险记录，未声称依赖无漏洞。
- 安装程序未配置代码签名。ZIP 与安装器已生成不等于安装/卸载全流程经过真实系统验收。
- 数据库备份不包含原始 `content/`、分析仓库或可迁移登录凭据。完整保存历史依据需要同时保留这些本地资料；移动或删除分析目录会影响历史代码证据读取。

## 实施中的决策记录

以下记录按实施顺序保留；代价指该决定的约束或判断错误时的影响。

1. 采用用户补充的“API + 订阅工具、飞书 CLI 优先”，替换原先飞书应用 token 优先并提前订阅工具接入。代价：每个 CLI 版本都需要独立验证能力与只读约束，未安装工具保持不可用。
2. 继续使用指定 D 盘根目录及独立本地分支，不另建 checkout。代价：共享目录会随分支变化，开始时确认没有并发用户修改。
3. ContextReader 绑定内存中的不可变任务快照，不为取证提前保存半份上下文。代价：IPC 必须只接收受项目范围约束的已存 ID，不能接受客户端构造上下文。
4. 所有路径索引，初始文本限定 150 文件 / 4 MiB / 前 400 行。代价：检索是部分覆盖，必须保留按固定提交读取和范围声明，不能凭零命中判定缺失。
5. 订阅工具采用输入材料模式，关闭原生工具、插件和 hooks，由平台提供取证工具；Codex 同时只读沙箱。代价：参数检查不能代替真实账户执行与约束验收，未声称已经完成。
6. 本阶段使用有上限的完整模型响应与真实任务/轮次事件。代价：不逐 token 展示，仍需校验工具和最终结果。
7. 保留用户正在运行的 0.1.0，新版输出到 `out/releases/0.2.0`；下载失败后复用此前校验过的 Electron ZIP 缓存，并重新比较其全部 73 个运行时文件。代价：必须选择正确的发行目录，缓存必须匹配锁定 Electron 版本。
