# 0.3.6 Jira 状态索引与预分析提示

Jira CLI 和账号登录共用的 JQL 增加状态限制，只索引“修复中、分析中、分配中”，同时保留项目、负责人及缺陷类型范围。三种状态在契约中统一声明，本地列表、单号读取和预分析校验复用同一规则。Trinity 状态规则维持现状。

远端列表返回的其他状态不会进入当前索引；升级前缓存的其他状态也不会再出现在工作台。成功刷新但没有符合条件的问题，仍显示空列表提示；接口错误仍明确显示失败。历史快照及报告保留，不因状态过滤删除。

按编号读取非允许状态会显示 ISSUE_STATUS_INACTIVE。提交预分析、执行代码更新前重新读取问题、报告发布前重新校验时均检查状态；若问题已关闭等，则终止本次流程并提示刷新列表，避免继续生成过期报告。

预分析按钮保留原有启用条件，并把禁用原因同时用于按钮提示、辅助说明及可见文本：项目停用、任务执行中、请求处理中、未关联 AI 执行连接。缺少关联时提供“配置 AI 连接”和“关联 AI 连接”，分别进入 AI 设置及当前项目编辑页。配置后仍需按既有流程选择模型或订阅工具、允许外发并保存，不会自动执行分析。
